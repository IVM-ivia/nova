Корпоративный веб-ресурс Invest Nova LG реализован на современном production-стеке с использованием серверного рендеринга, строгой типизации и автоматизированного CI/CD-деплоя.

Адаптивный дизайн

Проект построен на архитектуре App Router (Next.js 16) с клиентскими компонентами ('use client') для интерактивных модулей. Вся типизация — строгий TypeScript без ошибок компиляции. Стилизация реализована через централизованную систему CSS-переменных, обеспечивающую единый визуальный язык на всех страницах. Деплой автоматически запускается при каждом коммите в ветку main.

Раздел 2 / Модули и функциональность
Реализованные модули

Функциональные
модули сайта

Сайт состоит из пяти страниц, включая четыре интерактивных инструмента. Каждый модуль реализован как самостоятельный React-компонент с собственной логикой состояния.

Модуль 01 · /

Главная страница

Корпоративная посадочная страница компании с анимированным hero-блоком, секцией услуг, блоком кейсов и формой контакта.

  • Hero-секция с CSS-анимацией градиента и blur orb-эффектами
  • Блок услуг — 6 карточек с иконками и описаниями
  • Портфолио / секция кейсов
  • Секция «О компании» с ценностями
  • CTA-блок и форма для связи
Модуль 02 · /brandbook

Брендбук — бренд-система компании

Полная документация визуального и вербального стиля компании, реализованная как интерактивная веб-страница. Двуязычная: RU / EN.

  • Философия бренда: миссия, видение, 5 ценностей
  • Логотип: охранная зона, допустимые варианты, 6 запрещённых применений
  • Цветовая палитра: 8 цветов с HEX / RGB / CSS-переменными и функцией копирования
  • Шрифтовая шкала: 6 уровней с живыми превью
  • Иконография, анимации, голос бренда с парами примеров
  • Секция загрузки файлов (PDF, Figma, PNG)
Модуль 03 · /calc

Калькулятор стоимости проекта

Интерактивный многошаговый визард для расчёта ориентировочной стоимости разработки. Цены отображаются в фунтах стерлингов (£, en-GB).

  • 7 последовательных шагов выбора: тип проекта, функции, масштаб, дизайн, платформа, сроки, поддержка
  • Живой счётчик цены с анимацией обновления в реальном времени
  • Результирующий экран с детальной разбивкой по категориям
  • Полная i18n-поддержка на 7 языках
Модуль 04 · /brief

Онлайн-бриф клиента

Семишаговая форма сбора требований для старта проекта. Генерирует структурированный бриф с уникальным номером и датой.

  • 7 шагов: данные компании → тип проекта → стиль → аудитория → бюджет → сроки → контакты
  • Теги стилей (8 вариантов) и аудиторий (6 вариантов), мультиселект
  • Уникальный номер брифа, локализованная дата (en-GB)
  • Итоговый экран-подтверждение с резюме всех ответов
  • Полная i18n-поддержка на 7 языках
Модуль 05 · /tracker

Трекер проектов

Страница анонса готовящегося инструмента управления проектами с UI-демонстрацией будущего функционала.

  • Форма подписки на уведомление о запуске
  • Полноценный UI-мокап: сайдбар, прогресс по спринтам, карточки этапов, лента обновлений
  • 6 карточек с описанием функций трекера
  • Полная i18n-поддержка на 7 языках

Responsive design

The project is built on the Next.js 16 App Router architecture with Client Components ('use client') for all interactive modules. The entire codebase is written in strict TypeScript with zero compilation errors. Styling is delivered through a centralised CSS custom properties token system that enforces visual consistency across all pages. Deployment is triggered automatically on every commit to the main branch via Vercel.

Section 2 / Modules & Functionality
Delivered Modules

Functional
Modules

The platform comprises five pages including four interactive tools. Each module is implemented as an independent React component with its own state management logic.

Module 01 · /

Landing Page

Corporate landing page with animated hero section, services block, case studies and a contact form.

  • Hero section with CSS gradient animation and blur orb effects
  • Services block — 6 cards with icons and descriptions
  • Portfolio / case studies section
  • About the company section with core values
  • CTA block and contact form
Module 02 · /brandbook

Brandbook — Company Brand System

Complete visual and verbal identity documentation delivered as an interactive web page. Bilingual: RU / EN.

  • Brand philosophy: mission, vision, 5 values
  • Logo: clear space rules, permitted variants, 6 prohibited usages
  • Colour palette: 8 colours with HEX / RGB / CSS variables and copy-to-clipboard
  • Type scale: 6 levels with live previews
  • Iconography, motion principles, brand voice with right/wrong example pairs
  • Brand asset download section (PDF, Figma, PNG)
Module 03 · /calc

Project Cost Calculator

Interactive multi-step wizard for estimating development costs. Prices displayed in British Pounds (£, en-GB locale).

  • 7 sequential selection steps: project type, features, scale, design, platform, timeline, support
  • Live price counter with animated real-time updates
  • Result screen with itemised cost breakdown by category
  • Full i18n support across all 7 languages
Module 04 · /brief

Client Project Brief

Seven-step requirements intake form for project kick-off. Generates a structured brief with a unique reference number and date stamp.

  • 7 steps: company details → project type → style → audience → budget → timeline → contacts
  • Style tags (8 options) and audience tags (6 options), multi-select
  • Unique brief reference number, localised date format (en-GB)
  • Confirmation screen summarising all submitted responses
  • Full i18n support across all 7 languages
Module 05 · /tracker

Project Tracker

Announcement page for an upcoming project management tool, featuring a full UI demonstration of planned functionality.

  • Launch notification sign-up form
  • Full UI mockup: sidebar navigation, sprint progress, milestone cards, activity feed
  • 6 feature cards describing tracker capabilities
  • Full i18n support across all 7 languages
